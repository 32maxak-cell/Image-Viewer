🖼️ Image Viewer – Просмотрщик изображений на 7 языках
Мощный консольный просмотрщик изображений с поддержкой ASCII-арта, навигацией по папкам, масштабированием, поворотом и конвертацией форматов.
Отображает изображения прямо в терминале с использованием цветных пикселей или ASCII-символов.
Реализован на 7 языках программирования с единым интерфейсом командной строки.

🚀 Возможности
Отображение изображений – конвертация в ASCII-арт или цветные пиксельные блоки.

Навигация по папкам – переход между изображениями в текущей директории.

Масштабирование – увеличение/уменьшение отображаемого размера (опции -z, --zoom).

Поворот – вращение изображения на 90, 180 или 270 градусов (-r, --rotate).

Конвертация – сохранение в другой формат (-c, --convert).

Интерактивный режим – использование клавиш для управления в реальном времени:

← / → – предыдущее/следующее изображение.

+ / - – масштабирование.

r – поворот на 90°.

f – флип по горизонтали.

q – выход.

Цветной вывод – поддержка 24-битных цветов в терминале.

Кроссплатформенность – работает на Windows, Linux, macOS.

📖 Использование
Синтаксис (единый для всех версий):

bash
<команда> <файл_или_папка> [опции]
Аргументы
Аргумент	Описание
<файл>	Путь к изображению (если указан файл)
<папка>	Путь к папке (если указана, открывается первое изображение)
Опции
Опция	Описание
-z, --zoom <N>	Коэффициент масштаба (по умолчанию 1.0)
-r, --rotate <90|180|270>	Поворот изображения
-c, --convert <формат>	Конвертировать в формат (png, jpg, bmp, webp)
-o, --output <файл>	Выходной файл для конвертации
-a, --ascii	Использовать ASCII-символы вместо цветных блоков
-h, --help	Справка
Примеры
bash
# Открыть изображение с масштабом 2x
python image_viewer.py photo.jpg -z 2

# Открыть папку и просматривать изображения
python image_viewer.py ~/Pictures

# Конвертировать в PNG и сохранить
python image_viewer.py image.jpg -c png -o output.png

# Использовать ASCII-арт
python image_viewer.py photo.jpg -a
Управление в интерактивном режиме
Клавиша	Действие
← / →	Предыдущее/следующее изображение
+ / -	Увеличение/уменьшение масштаба
r	Поворот на 90°
h / v	Флип по горизонтали / вертикали
f	Переключить режим (цвет / ASCII)
q	Выход

🧠 Логика работы
Загрузка – чтение изображения из файла или выбор первого из папки.

Отображение – конвертация в ASCII-арт или цветные пиксели с учётом масштаба и поворота.

Навигация – переключение между файлами в директории.

Управление – обработка клавиш в интерактивном режиме (требуется поддержка терминала).

Экспорт – сохранение в другой формат при указании --convert или --output.

✨ Дополнительные фичи
ASCII-арт с символами разной плотности (например, █▓▒░ или @%#*+=-:.).

Цветные блоки – каждый пиксель отображается как цветной квадрат.

Авто-масштабирование – подгонка под размер терминала.

Кеширование – ускоренная навигация по папке.

Метаданные – отображение размера, формата и цветового пространства.
